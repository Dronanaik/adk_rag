## 1. API Design Conventions & Overview

- **Base URL Prefix:** `/api/v1`
- **Transport Protocols:**
  - **REST over HTTP/JSON:** Used for all CRUD operations, document management, Knowledge Graph inspection, Centralized Memory curation, and system configuration.
  - **Server-Sent Events (`text/event-stream`):** Used exclusively by `POST /api/v1/sessions/{session_id}/turns` to stream real-time Google ADK agent step transitions (`< 500ms` TTFS) and grounded response tokens.
- **Content Types:**
  - Standard requests/responses: `application/json; charset=utf-8`
  - Document upload (`POST /api/v1/documents/upload`): `multipart/form-data`
  - Chat turn stream (`POST /api/v1/sessions/{session_id}/turns`): `text/event-stream`
- **Timestamp & Identifier Conventions:**
  - All timestamps use ISO-8601 UTC format (`YYYY-MM-DDTHH:mm:ss.sssZ`).
  - All primary entity identifiers use UUIDv4 strings.
  - Every HTTP response includes an `X-Request-Id` header (UUIDv4) for end-to-end log correlation.

## 2. Authentication & Server-Side Authorization

Per `[APPROVED D-05]`, authentication and authorization are enforced strictly on the FastAPI backend—never trusted from client-side UI state alone.

### 2.1 Request Headers
| Header Name | Required | Allowed Values | Purpose |
| :--- | :---: | :--- | :--- |
| `X-App-Role` | Yes (default `researcher`) | `researcher`, `admin` | Identifies the active operational role selected in the workbench utility bar. |
| `X-Admin-Api-Key` | Required when `X-App-Role: admin` on mutating endpoints | String matching server `ADMIN_API_KEY` | Prevents unauthorized execution of administrative mutations (`UPLOAD`, `REINDEX`, `DELETE`, `PUT /settings`). |
| `X-Request-Id` | Optional | UUIDv4 string | Client-supplied trace ID (generated by server if omitted). |

### 2.2 Authorization Matrix
| Endpoint Category | `researcher` Role | `admin` Role (`+ Valid X-Admin-Api-Key`) | Internal `MemoryAgent` Service |
| :--- | :---: | :---: | :---: |
| **Read Operations (`GET /documents`, `/sessions`, `/kg/*`, `/memories`, `/settings`)** | Allowed | Allowed | Allowed |
| **Chat Session & Turn Execution (`POST /sessions`, `POST /sessions/{id}/turns`)** | Allowed | Allowed | Allowed |
| **Delete Session-Scoped Memory (`DELETE /memories/{id}` where `tier = SESSION`)** | Allowed (Own Session) | Allowed | Allowed |
| **Delete Shared Long-Term Memory (`DELETE /memories/{id}` where `tier = LONG_TERM_*`)** | Forbidden (`403`) | Allowed | Allowed (Supersede only) |
| **Commit New Long-Term Shared Memory (`LONG_TERM_SEMANTIC` / `LONG_TERM_EPISODIC`)** | Automatic via verified turn only | Allowed | Allowed (Post-Verifier only `D-04`) |
| **Document Upload, Re-index, Delete (`POST /upload`, `POST /reindex`, `DELETE /documents/{id}`)** | Forbidden (`403`) | Allowed | Forbidden |
| **Update System Settings (`PUT /api/v1/settings`)** | Forbidden (`403`) | Allowed | Forbidden |

## 3. Endpoints, Methods, and Request/Response Formats

### 3.1 Knowledge Base & Ingestion Endpoints (`/api/v1/documents`)

#### `POST /api/v1/documents/upload`
- **Purpose:** Uploads one or more `.pdf`, `.md`, or `.txt` files, computes SHA-256 content hashes for idempotency (`NFR-06`), creates `QUEUED` document records, and triggers asynchronous ingestion (`Chunking` → `Embedding` → `Schema-Guided KG Extraction`).
- **Authorization:** `admin`
- **Request (`multipart/form-data`):**
  - `files`: Array of binary file parts (`1` to `10` files per batch, max `25 MB` each).
  - `replace_existing`: Boolean (optional, default `false` — if `false` and `content_hash` already exists with `status = INDEXED`, returns existing record without re-running extraction).
- **Response (`202 Accepted`):**
  - `documents`: Array of document summary objects (`document_id`, `title`, `filename`, `mime_type`, `content_hash`, `file_size_bytes`, `status`, `deduplicated_hit`, `created_at`).

#### `GET /api/v1/documents`
- **Purpose:** Lists uploaded documents and their live pipeline metrics for Screen 2 (`Knowledge Base Manager`).
- **Authorization:** `researcher` or `admin`
- **Query Parameters:** `status` (optional filter: `QUEUED`, `CHUNKING`, `EXTRACTING_KG`, `INDEXED`, `FAILED`), `search` (optional substring match on `title`/`filename`), `limit` (default `25`, max `100`), `offset` (default `0`).
- **Response (`200 OK`):**
  - `items`: Array of document objects (`document_id`, `title`, `filename`, `mime_type`, `content_hash`, `file_size_bytes`, `status`, `error_message`, `chunk_count`, `entity_count`, `relation_count`, `created_at`, `updated_at`).
  - `summary_metrics`: Object (`total_documents`, `total_indexed_chunks`, `total_kg_entities`, `total_kg_relationships`).
  - `pagination`: Object (`total`, `limit`, `offset`, `has_more`).

#### `GET /api/v1/documents/{document_id}/chunks`
- **Purpose:** Retrieves ordered deterministic chunks and the specific Knowledge Graph entities/relationships extracted from each chunk for the Slide-Over Chunk Inspector (`DESIGN.md 10.2`).
- **Authorization:** `researcher` or `admin`
- **Query Parameters:** `limit` (default `20`, max `100`), `offset` (default `0`).
- **Response (`200 OK`):**
  - `document`: Document metadata object.
  - `items`: Array of chunk objects (`chunk_id`, `chunk_index`, `content`, `metadata` containing `page_number`, `section_heading`, `char_start`, `char_end`, `extracted_entities` array, and `extracted_relationships` array).
  - `pagination`: Object (`total`, `limit`, `offset`, `has_more`).

#### `POST /api/v1/documents/{document_id}/reindex`
- **Purpose:** Purges existing chunks and KG edges for a document (or retries a `FAILED` document) and restarts the async ingestion pipeline.
- **Authorization:** `admin`
- **Response (`202 Accepted`):** Updated document summary with `status = 'QUEUED'`.

#### `DELETE /api/v1/documents/{document_id}`
- **Purpose:** Performs transactional cascading deletion of the document, its chunks, its KG edges, and any `kg_entities` that become orphaned (`FR-16`).
- **Authorization:** `admin`
- **Response (`200 OK`):**
  - `deleted_document_id`: UUID
  - `removed_chunks_count`: Integer
  - `removed_relationships_count`: Integer
  - `removed_orphaned_entities_count`: Integer

### 3.2 Collaborative Chat & Multi-Agent SSE Endpoints (`/api/v1/sessions`)

#### `POST /api/v1/sessions`
- **Purpose:** Creates a new research conversation thread (`Screen 1`).
- **Authorization:** `researcher` or `admin`
- **Request Body:**
  - `title`: String (optional, default `"New Research Session"`; auto-titled after Turn 1 if default).
  - `use_shared_memory`: Boolean (default `true` — controls whether `LONG_TERM_SEMANTIC` and `LONG_TERM_EPISODIC` memories are recalled and written).
- **Response (`201 Created`):** `session_id`, `title`, `use_shared_memory`, `created_at`, `updated_at`.

#### `GET /api/v1/sessions`
- **Purpose:** Lists conversation sessions for the Left Context Rail (`Screen 1`), ordered by `updated_at DESC`.
- **Authorization:** `researcher` or `admin`
- **Query Parameters:** `limit` (default `30`, max `100`), `offset` (default `0`).
- **Response (`200 OK`):** Paginated list of session summary objects (`session_id`, `title`, `use_shared_memory`, `turn_count`, `updated_at`).

#### `GET /api/v1/sessions/{session_id}`
- **Purpose:** Loads full conversation history, resolved citation artifacts, and agent execution traces for a session.
- **Authorization:** `researcher` or `admin`
- **Response (`200 OK`):**
  - `session`: Session metadata (`session_id`, `title`, `use_shared_memory`, `created_at`, `updated_at`).
  - `turns`: Ordered array of turn objects (`turn_id`, `turn_index`, `user_query`, `assistant_response`, `grounding_status`, `citations`, `agent_execution_traces`, `total_latency_ms`, `created_at`).

#### `PATCH /api/v1/sessions/{session_id}`
- **Purpose:** Toggles `use_shared_memory` (`Session Only` vs. `Session + Shared Memory`) or renames the session title.
- **Authorization:** `researcher` or `admin`
- **Request Body:** `title` (optional string), `use_shared_memory` (optional boolean).
- **Response (`200 OK`):** Updated session object.

#### `POST /api/v1/sessions/{session_id}/turns` (Server-Sent Events Stream)
- **Purpose:** Submits a user query to the Google ADK 5-agent workflow (`Orchestrator` → `MemoryAgent` → `VectorRetriever` + `KGRetriever` → `SynthesisVerifier`) and streams real-time step telemetry and grounded response tokens (`Journey 2`).
- **Authorization:** `researcher` or `admin`
- **Request Body:**
  - `user_query`: String (required, `1` to `4,000` characters).
  - `use_shared_memory`: Boolean (optional override for the current turn).
- **SSE Event Stream Frames (`200 OK`, `Content-Type: text/event-stream`):**
  1. **`event: agent_step`** (Emitted at the start and completion of each specialized agent step):
     - Fields: `step_order` (int), `agent_name` (`Orchestrator` | `MemoryAgent` | `VectorRetriever` | `KGRetriever` | `SynthesisVerifier`), `action_or_tool` (string), `status` (`RUNNING` | `SUCCESS` | `FALLBACK` | `ERROR`), `summary` (human-readable status for the Live Agent Activity Stepper, e.g., `"Recalled 2 shared memories"`), `counts` (object with `chunks`, `kg_edges`, `memories`), `latency_ms` (int).
  2. **`event: token`** (Emitted as verified markdown text streams):
     - Fields: `delta` (string markdown fragment including inline citation tags `[Doc: ...]`, `[KG: ...]`, `[Mem: ...]`).
  3. **`event: turn_complete`** (Final frame containing full provenance and trace objects for instant Right Drawer inspection):
     - Fields:
       - `turn_id`: UUID
       - `turn_index`: Integer
       - `assistant_response`: Full verified markdown text
       - `grounding_status`: `GROUNDED` | `PARTIAL` | `INSUFFICIENT_EVIDENCE`
       - `fallback_warning`: String or `null` (populated if KG timed out or max step limit was reached)
       - `abstention_diagnostics`: Object or `null` (populated when `INSUFFICIENT_EVIDENCE`: `reason`, `searched_entities`, `searched_queries`, `recommended_action`)
       - `citations`: Object containing full hydrated records for every cited item:
         - `chunks`: Array of `{ citation_key, chunk_id, document_id, document_title, chunk_index, content, similarity_score, metadata, extracted_entities }`
         - `kg_paths`: Array of `{ citation_key, edge_id, source_entity, relation_type, target_entity, evidence_snippet, confidence, source_chunk_id, document_title }`
         - `memories`: Array of `{ citation_key, memory_id, memory_tier, content, source_turn_id, supporting_chunk_ids, created_at }`
       - `subgraph`: Object `{ nodes: [...], edges: [...] }` representing the bounded 1–2 hop local neighborhood retrieved during the turn (`DESIGN.md 4.4`)
       - `agent_execution_traces`: Ordered array of persisted `AgentExecutionTrace` records
       - `total_latency_ms`: Integer
  4. **`event: error`** (Emitted if an unrecoverable error occurs mid-stream):
     - Fields: `code`, `message`, `retryable` (boolean), `request_id`.

### 3.3 Knowledge Graph Explorer Endpoints (`/api/v1/kg`)

#### `GET /api/v1/kg/entities`
- **Purpose:** Searches and filters canonical Knowledge Graph nodes (`Screen 3 Sub-View A`).
- **Authorization:** `researcher` or `admin`
- **Query Parameters:** `search` (optional name/alias substring query), `entity_type` (optional filter: `System`, `Component`, `Organization`, `Person`, `Concept`, `Process`, `Policy`, `Location`, `Event`), `document_id` (optional UUID filter), `limit` (default `25`, max `100`), `offset` (default `0`).
- **Response (`200 OK`):** Paginated list of `kg_entities` (`entity_id`, `canonical_name`, `entity_type`, `aliases`, `description`, `source_chunk_ids`, `source_document_ids`, `degree_count`).

#### `GET /api/v1/kg/entities/{entity_id}/subgraph`
- **Purpose:** Executes the `traverse_kg_subgraph` database function (`1` or `2` hops) around a selected canonical entity and returns its local graph neighborhood plus verbatim backing document chunks (`Screen 3 Sub-View A`).
- **Authorization:** `researcher` or `admin`
- **Query Parameters:** `hops` (integer `1` or `2`, default `1`).
- **Response (`200 OK`):**
  - `center_entity`: Full `KGEntity` record.
  - `nodes`: Array of connected `KGEntity` nodes within `hops` distance (capped at `50` highest-confidence nodes for UI legibility).
  - `edges`: Array of directed `KGRelationship` edges (`edge_id`, `source_entity_id`, `target_entity_id`, `relation_type`, `evidence_snippet`, `confidence`, `source_chunk_id`, `document_id`).
  - `supporting_chunks`: Array of verbatim `DocumentChunk` records referenced by the returned edges.

### 3.4 Centralized Memory Explorer Endpoints (`/api/v1/memories`)

#### `GET /api/v1/memories`
- **Purpose:** Searches and filters Centralized Memory records across tiers (`Screen 3 Sub-View B`).
- **Authorization:** `researcher` or `admin`
- **Query Parameters:**
  - `memory_tier`: Optional filter (`SESSION`, `LONG_TERM_SEMANTIC`, `LONG_TERM_EPISODIC`).
  - `session_id`: Optional UUID filter.
  - `include_superseded`: Boolean (default `false` — when `false`, returns only active memories where `superseded_by_id IS NULL`).
  - `search`: Optional semantic or substring query.
  - `limit` (default `25`, max `100`), `offset` (default `0`).
- **Response (`200 OK`):** Paginated list of `MemoryEntry` objects (`memory_id`, `memory_tier`, `session_id`, `content`, `related_entity_ids`, `source_turn_id`, `supporting_chunk_ids`, `superseded_by_id`, `created_at`) with resolved entity names and document titles.

#### `DELETE /api/v1/memories/{memory_id}`
- **Purpose:** Permanently deletes ("Forgets") a memory record (`FR-11`).
- **Authorization:**
  - `researcher`: Allowed only if `memory_tier == 'SESSION'`.
  - `admin`: Allowed for any `memory_tier` (`SESSION`, `LONG_TERM_SEMANTIC`, `LONG_TERM_EPISODIC`).
- **Response (`200 OK`):** `{ "deleted_memory_id": "uuid", "memory_tier": "LONG_TERM_SEMANTIC" }`.

#### `GET /api/v1/settings`
- **Purpose:** Fetches current runtime retrieval/orchestrator settings and live integration telemetry (`Screen 4`).

- **Response (`200 OK`):** Updated `settings` object.

## 4. Internal Google ADK Agent Tool Contracts

Inside the Python backend, the **Orchestrator Agent** and sub-agents communicate via strictly typed internal Python tool functions that read and mutate `TurnWorkingState` (`FR-06`). These tools are internal to the backend process and are never exposed as public unauthenticated HTTP endpoints:

| Internal ADK Tool Name | Invoking Agent | Input Arguments | Output Written to `TurnWorkingState` |
| :--- | :--- | :--- | :--- |
| `recall_centralized_memory` | `MemoryAgent` | `query_text`, `entity_names[]`, `session_id`, `include_shared_memory` | `recalled_memories[]` (active `SESSION` + `LONG_TERM_*` entries above similarity threshold). |
| `search_document_chunks` | `VectorRetrievalAgent` | `sub_query`, `top_k`, `min_similarity` | `retrieved_chunks[]` (deduplicated by `chunk_id`, ordered by cosine similarity). |
| `traverse_knowledge_graph` | `KnowledgeGraphAgent` | `candidate_entities[]`, `max_hops` | `resolved_entities[]`, `kg_paths[]` (triples), and `kg_backing_chunks[]` (`source_chunk_id`s). |
| `verify_and_format_citations`| `SynthesisVerifierAgent`| `draft_markdown`, `citations_used[]` | Validates every `[Doc]`, `[KG]`, and `[Mem]` tag against `TurnWorkingState`; sets `grounding_status`. |
| `consolidate_verified_memory`| `MemoryAgent` | `verified_facts[]`, `turn_id`, `supporting_chunk_ids[]`, `entity_ids[]` | Deduplicates against existing `memory_entries`, updates `superseded_by_id` if conflicting, and commits new `LONG_TERM_*` records (`D-04`). |

## 5. Validation & Error Conventions

### 5.1 Standard Error Envelope
All non-2xx HTTP responses return a consistent JSON error envelope:
- `error.code`: Machine-readable uppercase error code (e.g., `VALIDATION_ERROR`, `ADMIN_ROLE_REQUIRED`, `DOCUMENT_NOT_FOUND`, `FILE_TOO_LARGE`, `UNSUPPORTED_MEDIA_TYPE`, `LLM_RATE_LIMITED`, `DATABASE_UNAVAILABLE`).
- `error.message`: Clear, user-safe explanation suitable for UI display.
- `error.details`: Optional object containing field-level validation failures or diagnostic context.
- `error.request_id`: UUIDv4 matching the `X-Request-Id` response header.

### 5.2 HTTP Status Code Mapping
| Status Code | Error Code(s) | Trigger Condition |
| :--- | :--- | :--- |
| `400 Bad Request` | `VALIDATION_ERROR`, `EMPTY_QUERY` | Malformed JSON, query parameter out of range, or empty chat query. |
| `401 Unauthorized` | `INVALID_ADMIN_KEY` | `X-App-Role: admin` supplied on a mutating endpoint with a missing or invalid `X-Admin-Api-Key`. |
| `403 Forbidden` | `ADMIN_ROLE_REQUIRED`, `MEMORY_SCOPE_FORBIDDEN` | `researcher` role attempting document upload/deletion, settings mutation, or global `LONG_TERM_*` memory deletion. |
| `404 Not Found` | `DOCUMENT_NOT_FOUND`, `SESSION_NOT_FOUND`, `ENTITY_NOT_FOUND`, `MEMORY_NOT_FOUND` | Requested UUID does not exist in Supabase PostgreSQL. |
| `409 Conflict` | `INGESTION_IN_PROGRESS` | Attempting to re-index or delete a document currently in `CHUNKING` or `EXTRACTING_KG` state. |
| `413 Content Too Large`| `FILE_TOO_LARGE` | Uploaded file exceeds `MAX_UPLOAD_SIZE_MB` (`25 MB`). |
| `415 Unsupported Media Type`| `UNSUPPORTED_MEDIA_TYPE` | Uploaded file is not `.pdf`, `.md`, or `.txt`, or PDF contains zero extractable text (scanned image without text layer). |
| `429 Too Many Requests` | `RATE_LIMIT_EXCEEDED`, `LLM_RATE_LIMITED` | Client exceeded API rate limit or upstream Gemini API quota is temporarily exhausted after retries. |
| `503 Service Unavailable`| `DATABASE_UNAVAILABLE`, `UPSTREAM_LLM_UNAVAILABLE` | Supabase connection pool or Gemini API unreachable after retry budget. |

## 6. Pagination, Filtering & Sorting Rules

All list endpoints (`GET /documents`, `GET /documents/{id}/chunks`, `GET /sessions`, `GET /kg/entities`, `GET /memories`) enforce bounded offset pagination:
- `limit`: Integer, default `25`, minimum `1`, maximum `100` (requests above `100` are rejected with `400 VALIDATION_ERROR`).
- `offset`: Integer, default `0`, minimum `0`.
- **Standard Pagination Metadata Object:** Every paginated response includes `pagination: { total, limit, offset, has_more }`.
- **Deterministic Ordering:**
  - `GET /documents`: Ordered by `created_at DESC, document_id ASC`.
  - `GET /documents/{id}/chunks`: Ordered by `chunk_index ASC`.
  - `GET /sessions`: Ordered by `updated_at DESC, session_id ASC`.
  - `GET /kg/entities`: Ordered by `canonical_name ASC` (or vector similarity when a semantic search query is active).
  - `GET /memories`: Ordered by `created_at DESC` (or vector similarity when `search` is provided).

## 7. External APIs, Integrations & Webhooks

### 7.1 Google Gemini API (`google-genai` / `google-adk`)
- **Models Used:**
  - **Reasoning & Structured Extraction:** `gemini-2.5-flash` (configured via `GEMINI_MODEL_NAME`).
  - **Vector Embeddings:** `text-embedding-004` (`768` dimensions, configured via `GEMINI_EMBEDDING_MODEL`).
- **Integration Safeguards:**
  - All ingestion KG extraction calls enforce `response_mime_type = "application/json"` and pass the strict Pydantic schema (`D-03`) so malformed triples cannot enter the database.
  - Embedding requests batch up to `32` chunks per API call to minimize network round-trips during document ingestion.
  - Upstream calls enforce a `15s` request timeout and automatic exponential backoff (`1s`, `3s` with jitter) on HTTP `429` or `5xx` responses.

### 7.2 Supabase PostgreSQL Integration
- **Connection Management:** Server-side async connection pool (`asyncpg` / SQLAlchemy 2.0 AsyncEngine) initialized during FastAPI lifespan startup (`min_size=2`, `max_size=10`, `command_timeout=15s`).
- **Database RPC / SQL Functions:**
  - `traverse_kg_subgraph(seed_entity_ids UUID[], max_hops INT)`: Executes bounded 1–2 hop recursive CTE traversal with cycle prevention directly inside PostgreSQL, returning deduplicated edges and node IDs in a single round-trip.

### 7.3 Asynchronous Status Notification (Polling & Optional Webhook Pattern)
- **MVP Primary Mechanism:** Because the frontend workbench and FastAPI backend operate as a cohesive web application, real-time chat progress uses **SSE (`POST /sessions/{id}/turns`)** and document ingestion progress uses **lightweight conditional polling (`GET /api/v1/documents` every `2.5s` only while any document is in `QUEUED`, `CHUNKING`, or `EXTRACTING_KG` status)**.
- **Optional Outbound Ingestion Webhook (`INGESTION_WEBHOOK_URL`):** If configured via environment variable for external automation, the backend dispatches a `POST` notification upon document completion (`INDEXED` or `FAILED`) signed with an `X-Webhook-Signature` header (`HMAC-SHA256` using `WEBHOOK_SECRET`).

## 8. Rate Limiting & Concurrency Controls

To protect both the backend server and upstream Gemini API quotas without requiring external Redis infrastructure in the MVP, rate limiting and concurrency are enforced in-process:

| Limiter Scope | Limit / Policy | Enforcement Mechanism |
| :--- | :--- | :--- |
| **Chat Turn Execution (`POST /sessions/{id}/turns`)** | Max `15` turns per minute per client IP; max `1` active streaming turn per `session_id` at a time. | In-memory token bucket + active session lock (`429 RATE_LIMIT_EXCEEDED` with `Retry-After` header). |
| **Document Upload (`POST /documents/upload`)** | Max `10` files per upload request; max `2` concurrent background document ingestion jobs. | Async `asyncio.Semaphore(2)` queue on the ingestion worker; additional uploads wait in `QUEUED` status. |
| **Gemini LLM & Embedding Calls (Ingestion)** | Max `4` concurrent chunk extraction requests to Gemini API. | Async `asyncio.Semaphore(4)` + exponential backoff on `429`. |
| **Orchestrator Agent Step Budget (`NFR-03`)** | Hard limit of `max_agent_steps` (default `5`, max `8`) and `turn_timeout_seconds` (default `30s`) per turn. | Enforced by Orchestrator circuit breaker (`ARCHITECTURE.md Section 11`). |

## 10. Data Privacy & Fault-Tolerant Failure Handling

### 10.1 Data Privacy & Secret Isolation
1. **Zero Client Secret Exposure (`NFR-08`):** The frontend bundle (`VITE_*`) contains only the relative or local backend API base URL (`/api/v1`). It never receives `GOOGLE_API_KEY`, `DATABASE_URL`, or `SUPABASE_SERVICE_ROLE_KEY`.
2. **Untrusted Evidence Sandboxing:** Before passing retrieved `document_chunks.content`, `kg_relationships.evidence_snippet`, or `memory_entries.content` to any Google ADK agent prompt, the backend wraps each artifact in `<source_evidence citation_id="...">...</source_evidence>` tags and strips control characters to neutralize indirect prompt injection.
3. **Log & Trace Redaction:** Request logs and `agent_execution_traces` never log HTTP authorization headers (`X-Admin-Api-Key`) or environment variables.

### 10.2 Fault-Tolerant Degradation Matrix
| Failure Condition | API / Stream Behavior | User-Visible Outcome |
| :--- | :--- | :--- |
| **Knowledge Graph Agent Timeout (`> 8s`) or Zero Entity Match** | Emits `event: agent_step` with `status: "FALLBACK"` for `KGRetriever`. Orchestrator proceeds using `VectorRetriever` + `MemoryAgent` results (`NFR-05`). | Turn completes normally with `grounding_status: "PARTIAL"` and displays an amber fallback notice in the response header. |
| **Memory Consolidation Failure Post-Synthesis** | Synthesis response and citations are already streamed to the user; memory write error is logged non-fatally in `agent_execution_traces`. | User still receives their full grounded answer without interruption. |
| **Orchestrator Hits Max Step / Timeout Budget (`30s`)** | Circuit breaker stops sub-agent calls and instructs `SynthesisVerifier` to summarize verified evidence gathered so far. | Emits `turn_complete` with `grounding_status: "PARTIAL"` and lists any unanswered sub-questions. |
| **Document Fails Mid-Ingestion** | Database transaction for the failed stage rolls back cleanly; `documents.status` is set to `'FAILED'` with `error_message`. | `GET /api/v1/documents` shows `FAILED` status and reason; Admin can click `Retry` (`POST /reindex`) or `Delete`. |
| **Client Disconnects Mid-SSE Stream** | FastAPI detects disconnected request socket (`request.is_disconnected()`) and cancels pending downstream sub-agent calls. | Prevents wasted Gemini token spend on abandoned requests. |
